Curriculum Vitae

Research interests

  • machine learning in computational biology
  • computational epigenomics
  • in-silico drug recommendation and precision medicine
  • prediction of deleterious genetic variants
  • prediction of protein stability changes
  • protein structure prediction

Services and downloads

  • KRL
    • GitHub repository for the kernelized rank learning (KRL) for personalized drug recommendation
  • DDIG
    • web-server for predicting disease-causing indels, nonsense and synonymous mutations
  • EASE-MM
    • web-server for predicting mutation-induced stability changes
  • EASE-AA
    • an older version of my method for predicting mutation-induced stability changes
